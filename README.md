# Target Shooting 2D Unity

Game heeft 1 scherm, geen split-screen.
2 cannons die schieten naar targets.
Targets komen met een script, willekeurig op een vierkant radius op het scherm tevoorschijn.
1 Target is 100 punten
Als je 2 targets binnen 2 seconden schiet krijg je een multiplier van 2x die optelt naar 4x max (1 target per seconde)
Bijvoorbeeld:
4 targets in 4 seconden =
100 -> 200 = 300 + 300 = 600 + 400 = 1000 punten totaal.

Timer van 1 minuut, wie de meeste punten heeft wint de ronde
